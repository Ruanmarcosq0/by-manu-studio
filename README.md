# By Manu Studio

Site editorial com paleta de bege areia, taupe e marrom espresso em Next.js, React e TypeScript. CSS responsivo sem biblioteca de componentes ou JavaScript de interação desnecessário.

## Desenvolvimento

Node 22+ e pnpm. Execute `pnpm install`, `pnpm dev`. Para validar: `pnpm build` e `pnpm typecheck`. Produção: `pnpm start`.

## Conteúdo

Dados comerciais centralizados em `data/site.config.ts`. Fontes verificadas: Instagram público @by_manustudio e página oficial maapp.com.br/studiomanuellaborges, consultados em 24/10/2026. Técnicas extraídas dos destaques públicos; endereço e WhatsApp da página oficial vinculada à bio. Não foram inventados preços, avaliações, horários, formações ou políticas. Fotografias originais do perfil em cores naturais; links para as publicações originais disponíveis no portfólio.

O processo descreve os passos do visitante para consultar e reservar, sem afirmar protocolos internos não verificados. Retrato da profissional obtido da agenda oficial, que também confirma os procedimentos descritos. A marca tipográfica do cabeçalho é uma composição editorial, não reprodução de um logotipo oficial.

## Deploy

Importar este repositório em um novo projeto Vercel com framework Next.js e branch main. A origem canônica usa `NEXT_PUBLIC_SITE_URL` ou `VERCEL_PROJECT_PRODUCTION_URL`. Configure a variável caso adote domínio próprio. Sem segredos ou analytics instalados. Os atributos data-event marcam pontos de integração futura; não enviam eventos a provedores externos.

SEO: metadata, canonical, Open Graph gerado, Twitter Card, sitemap, robots, llms.txt, JSON-LD BeautySalon. Sem notas ou avaliações fictícias. FAQ nativo acessível, âncoras, link de pular conteúdo, foco visível e movimento reduzido.
